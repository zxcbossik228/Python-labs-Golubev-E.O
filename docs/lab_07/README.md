# Лабораторная работа №7 — вариант 5

**Тема варианта:** гостиница. Бронирование, заселение, выселение и расчёт стоимости.

В папке две архитектуры:
- `bad_version.py` — намеренно проблемная версия для анализа нарушений SOLID;
- остальные файлы — отрефакторенная версия.

В финальной версии показаны все принципы SOLID:
- **SRP** — `RoomService`, `BookingService`, `ReportService`, `ConsoleUI`, Repository и Notifier имеют отдельные ответственности;
- **OCP** — новые тарифы и способы уведомления добавляются отдельными классами;
- **LSP** — `StandardRoom` и `LuxuryRoom` взаимозаменяемы как `Room`;
- **ISP** — интерфейс хранилища разделён на `ReadRepository` и `WriteRepository`;
- **DIP** — сервисы зависят от Protocol-интерфейсов, зависимости передаются через конструктор (Dependency Injection).

Есть интерактивное меню и 6 автоматических тестов.

Запуск: `RUN.bat` или `python main.py`.
Тесты: `python -m unittest -v tests.py`.
