# Лабораторная работа №6 — вариант 5

**Тема варианта:** гостиница. Управление номерами, гостями и бронированиями.

Реализовано по методичке:
- `dataclass` для сущностей;
- `Enum` для статусов номера и бронирования;
- базовый класс и несколько специализированных сущностей;
- 3 собственных декоратора, включая декоратор с параметром и `@wraps`;
- собственный контекстный менеджер `OperationContext`;
- `Protocol` (`Reportable`), которому соответствуют разные классы;
- интроспекция через `type`, `isinstance`, `hasattr`, `getattr`, `dir`, `inspect`;
- обработка ошибок, консольное меню и статистика;
- статусы номера: свободен, забронирован, занят, на обслуживании.

Запуск: `RUN.bat` или `python main.py`.
Тесты: `python -m unittest -v tests.py`.
