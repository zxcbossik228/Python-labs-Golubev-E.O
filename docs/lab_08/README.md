# Лабораторная работа №8 — вариант 5

**Тема варианта:** система бронирования гостиничных номеров.

Реализованы обязательные паттерны:
- **Repository** — `Repository` + `InMemoryRepository`;
- **Factory** — `RoomFactory`: стандартный номер, люкс, семейный номер;
- **Strategy** — обычный, сезонный и тариф выходного дня;
- **Observer** — `ConsoleObserver` и `HistoryObserver` получают события бронирования и смены тарифа.

Также используются `dataclass`, `Enum`, композиция и разделение бизнес-логики по классам.
Есть интерактивное меню и 7 автоматических тестов.

Запуск: `RUN.bat` или `python main.py`.
Тесты: `python -m unittest -v tests.py`.
